COOP/COEP note: GitHub Pages cannot send cross-origin-isolation headers, so ONNX Runtime Web's WASM backend runs single-threaded there. This page pins ort.env.wasm.numThreads = 1 and loads the WASM from a CDN with CORS, so it is designed to work without Cross-Origin-Opener-Policy / Cross-Origin-Embedder-Policy. The live status above shows the backend and crossOriginIsolated value observed in the browser — this spike has not been run on a real phone.
